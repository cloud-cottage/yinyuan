## 三、`W-YS-5` 结案（「沿用」）—— 落位 §7.13-2；判据 AC-130 ／ AC-131 ／ AC-132

| 项 | 口径 |
| --- | --- |
| 适用面 | **`/api/v1/**` 全部端点**（含今后新增；新增端点不得另设上限而不升版） |
| 计数键 | **一次「鉴权通过」的 API key**（`Authorization` 优先；仅其缺失 / 空串时取 `X-API-Key`） |
| **不计数** | **401 / 404 / 405 / 503 / 预检 `OPTIONS`(204)**（攻击面与枚举面不得耗尽合法额度） |
| **计数** | **通过鉴权后的全部请求**（含 200 / 400 / 500） |
| 窗口 | **`Asia/Shanghai` 自然日 `00:00:00` 重置**（不得按 UTC） |
| 上限 | **1000 次 / 键 / 自然日**；**不设 QPS 上限** |
| 超限 | **`429`** ＋ `{ok:false, reason:"RATE_LIMITED", message:"今日调用次数已达上限，请明日再试。"}`（**原六值 `reason` 一字不改**；`RATE_LIMITED` 为**新增第七值**） |
| 可选头 | `X-RateLimit-Limit` / `-Remaining` / `-Reset` —— **不出现不判负**；出现则语义须正确 |
| 缓存 | **429 属错误面 ⇒ 不得缓存**（§7.12-4 错误面枚举自本版含 429；旧句保留） |
| **硬约束（可判负）** | **不得因限流实现回退可用性**：不得新增 `regions` / 不得因限流存储故障使业务端点 `5xx` / **AC-126「非 200 ＝ 0」优先且 429 不得豁免**（复跑前须确认余量 ≥ 计划发数） |
| 存储选型 | **待 Kevin ⇒ `W-YS-8`**；**选型本身不判负**，但**违反硬约束仍判负**（选型自由 ≠ 豁免） |
| 计费 | **「沿用」只指限流，不含计费**（§4 与 §7.10 的免费只读定性不变） |

## 四、`W-YS-6` 结案（「开浏览器直连」）—— 落位 §7.13-3；判据 AC-133 ～ AC-136

| 项 | 口径 |
| --- | --- |
| Allow-Origin | **`*`**；**不得带 `Allow-Credentials`**；**不得反射 `Origin`**（故**不新增 `Vary: Origin`**） |
| Allow-Methods | **`GET, OPTIONS`**（不得含 POST / PUT / PATCH / DELETE / HEAD） |
| Allow-Headers | **`Authorization, X-API-Key, Content-Type`**（不得用 `*`） |
| 预检 | **`OPTIONS` ＋ `Origin` ＋ `Access-Control-Request-Method` ⇒ `204`（无体、三头齐）**；`Max-Age: 600`（可选，提供则须为 600） |
| **非预检 `OPTIONS`** | **仍 `405` ＋ `Allow: GET` ＋ JSON 信封**（AC-103 在该面继续有效） |
| **AC-103 收窄** | **仅「预检 OPTIONS」例外**；其余方法一律仍 `405`（旧行原文一字未改、另立取代注） |
| 错误面 | **401 / 404 / 405 / 429 / 500 / 503 均须带 `Allow-Origin`**（否则浏览器读不到错误体） |
| 缓存 / 头 | `Cache-Control: no-store`、`Vary: Authorization, X-API-Key`、仅 200 用 `Vercel-CDN-Cache-Control` —— **全部不变** |
| 安全提示 | **须在 `/docs` 页登记**：浏览器内用 key 会暴露给终端用户，**官方建议走后端代理**；**禁写「前端直连安全 / 可把 key 写进前端 / `*` 是访问控制」** |
