### 7.8 印索 ↔ xiai-api 内容面接入（2026-09-23 **v1.35 新增**｜追溯 **R-101**（二次封装口径，沿用）／**R-102**（块数以 xiai TileSplicer 真源为准）＋ **派单方 2026-09-23 定**；修订人 Jing）

> 口径来源：**本节五项口径全部由派单方 2026-09-23 定**（**非本单实测**）；**跨仓引用纪律见 §7.8-5**；**xiai 侧对端口径只引编号与语义**（**§3.28 / §3.29**），**不复制其条文**。

**§7.8-1 二次封装口径（R-101；印索只消费、不自持实现）**

- **xiai-api 是印索的内容数据提供者**——**印索只经自己的 api 层封装消费 xiai-api 的输出**（包签名 / URL / TTL / 字段名，沿用 §7.7 v1.34 注）。
- **印索不得自持切分 / 转码实现**：**不得**在本工程内另写切割、切片、几何重算或转码逻辑（**含「为对齐 xiai 而二次实现一份」**）。
- **几何真源恰 1 处 ＝ xiai 侧 `src/tilesplicer/**`**——**切向 / 切位 / 块数 / 源尺寸等几何量的唯一真源在该处**；**印索侧一律透传，不重算、不落第二真源**。
- **边界（与 §7.7 v1.34 注一致）**：**只走 HTTP 契约**、**不得 import xiai 源码**、**xiai 不可用 ⇒ 结构化失败**（**不得造伪数据、不得以空切片数组 / 占位图冒充成功**）。

**§7.8-2 代理口径（三键并列；不 rewrite 前缀；target 写 `127.0.0.1`）**

- **`/api/image` → `http://127.0.0.1:5191`**，与 **`/api/tilesplicer`（→ `http://127.0.0.1:5163`）**、**`/feicui`（→ `http://127.0.0.1:5195`；v1.27 / 附录 B-B4 已登记）** **并列**（同一 dev server 的 `server.proxy` 与 `preview.proxy` 内**各一**）。
- **不 rewrite 前缀**（目标侧按原前缀接收；与 `/feicui` 键同形态）。
- **target 一律写 `127.0.0.1`，不得写 `localhost`**——**理由 ＝ 按站实测地址族（5191 只绑 IPv4）**；**该理由为派单方给定，本单未复测**。
- **连带**：**5164 仍独占、`strictPort: true` 不变、不新占端口**（附录 B-B4）；**不新增任何 SPA 路由 ⇒ §2.2 路由表仍 14 条**、**AC-88 / AC-89 扫描面不变**；**生产部署须网关同构改写**（同 `/feicui` 的已知坑）。
- **登记留痕**：**`/feicui`（→ 5195）系 v1.27 既有登记**；**`/api/tilesplicer`（→ 5163）与 `/api/image`（→ 5191）两键本文件此前未登记，由本版一并登记**（**来源 ＝ 派单方 2026-09-23 定**）。

- **引用纪律**：三件的**语义与取值以 xiai 侧现行条文为准**；**本文件只写「面别 / 路径 / 判据要点」**，**不复制 xiai 侧正文**（**§7.8-5**）。

**§7.8-4 不可达 / 无 digest / 无二进制时如实降级（不得伪造、不得白屏、不得抛未捕获异常）**

- **三类触发面**：**① xiai-api 不可达**（连接被拒 / 超时）；**② 无 digest**（摘要字段缺失或为空）；**③ 无二进制**（无字节 / 空体 / 非预期内容）。
- **唯一许可行为 ＝ 如实降级**：**结构化失败**（明确失败态 ＋ 可读原因）＋ **对客可读提示**（不暴露实现标识，遵 §1.6 / AC-88 / AC-89）＋ **页面三态齐备**（空态 / 加载态 / 错误态；§1.6 / AC-03）。
- **三条禁令（逐条可判负）**：**① 不得伪造数据**（不得以占位图 / 空切片数组 / 编造 digest 冒充成功）；**② 不得白屏**；**③ 不得抛未捕获异常**（console 无未捕获异常，与 AC-05 一致）。

- **xiai 侧变更不得自动套到印索**：**xiai 规范 / 实现升版后，本文件跨仓判据不随之自动生效**——**须由印索线按 §0.4 升版并留痕**（**未走流程者一律视为未生效**）。
