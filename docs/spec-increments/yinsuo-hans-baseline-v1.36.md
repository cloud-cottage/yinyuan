### 7.9 印索全站简体与跳站边界（2026-09-23 **v1.36 新增**｜追溯 **§2.1 站点结构（上屏文案面）** ＋ **§0.1 R11（站点中文单语，英文术语保留）**｜来源 ＝ **Kevin 2026-09-23 定**）

**§7.9-1 全站简体为既定状态**

- **印索面向用户的上屏文案一律简体**；**文案与菜单均用简体**（**菜单 / 导航项名同属上屏文案，一并适用**）。
- **用户自行输入除外**——**用户自己输入的内容（表单填写、搜索词、备注等）由其本人决定**，**不属上屏文案范畴**；**印索不对其作任何字形转换**、**不因此判负**。
- **「上屏文案」＝ 面向用户渲染的中文文字**：营销站与控制台的**页面文案**、**菜单与导航项名**、**按钮 / 表单标签**、**提示与错误文案**、**空 / 加载 / 错误三态文案**、**占位与未开放页文案**、**图表与图例文字**、**`document.title` 与 `title` / `aria-label` / `alt` 等可读无障碍文字**。
- **排除面（不属上屏文案、不得列为判负面）**：**源码注释**、**`docs/**` 规范与文档**、**机器字面值**（**键名 / 枚举值 / 类型码 / 路径 / 配置键**）、**第三方名称与英文术语**（**与 §0.1 R11「站点中文单语，英文术语保留」并存**——**R11 管「单语与术语」、本节管「字形」**）。
- **字形口径 ＝ 沿用现行字形的简体中文**——**不引入任何字形转换机制、不新增转换依赖、不新增运行时第三方库**；**本条只登记既定状态**，**不要求任何实现改动**。

**§7.9-2 封堵句（限定读法）**

- **本条为「限定读法」条款**（**性质同 xiai 侧 v1.28 的 AC-148 限定句**；**只引编号与语义、不复制其条文**）：**下列两种读法一律无效**。
- **① 不得据「印索出现简体」判负**——**任何角色（实现 / 质检 / 评审）不得以「印索页面为简体」为判负理由**；**凡据此判负的结论，判定无效**。
- **② 也不得据本条把印索强行转繁**——**任何角色不得据本条、或据玺爱（xiai）侧的繁体化条款，要求印索把上屏文案转为繁体**；**凡据此提出的改动要求，一律无效**。
- **无效形态**：**未按上述限定读法而据此判负 / 据此要求改动者，其判定与要求自始无效**——**不得作为验收证据留档、不得据此开缺陷单、不得据此判定任何合规实现不合格**。

**§7.9-3 跳站边界：玺爱的繁体红线仅适用玺爱**

- **玺爱（xiai）的繁体化红线（含其上屏繁体要求及其繁体化判据）适用范围仅限玺爱**；**印索不适用、不得自动套用**。
- **两站是不同站点、各有其字形既定状态**——**印索 ＝ 简体既定**（§7.9-1）**／ 玺爱 ＝ 繁体既定**（其口径归玺爱线）；**任一站点不得据自己的字形口径去改动另一站点**。
- **跨站引用纪律（沿用 §7.8-5）**：印索引用玺爱条款时**只引编号与语义、不复制条文**；**玺爱规范 / 实现升版后，本文件跨仓判据不随之自动生效**——**须由印索线按 §0.4 升版并留痕**（**未走流程者一律视为未生效**）。
